# basic-python

A small collection of beginner-friendly Python scripts demonstrating basic language features (printing, working with the OS module, and importing/using external modules).

## What’s in this repo?

- `hello_world.py` — the classic first program.
- `printing_multi_line.py` — examples of printing multi-line strings.
- `going-in-os.py` — simple usage patterns around Python’s `os` module.
- `try-external-modules.py` — a simple example that imports and uses a third‑party module.

## Requirements

- Python 3.x

## How to run

From the repo root:

```bash
python hello_world.py
python printing_multi_line.py
python going-in-os.py
python try-external-modules.py
```

## Notes

- If `try-external-modules.py` imports a package you don’t have installed, install it first with `pip install <package-name>`.
